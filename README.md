# AttoLang Playground

A self-hosted, static **Atto source → WebAssembly compiler → WebAssembly guest** demo. Both compiler and generated program execute inside the visitor's browser. No compilation server and no user-code uploads.

The compiler is a freestanding C bootstrap compiled itself to `atto_compiler.wasm` with Clang. It emits **real binary Wasm**, not a JavaScript simulation. This is an intentionally narrow M0 slice; the full canonical frontend/backend must replace it before full language conformance can be claimed. See [the exact grammar](docs/COMPILER_CONTRACT.md).

## Verify locally

Requires Clang with wasm32 support, wasm-ld, Node >=20 and Python 3 for the optional HTTP server. No npm dependencies.

```sh
npm run verify
npm run serve
# Visit http://localhost:8080
```

`npm test` executes the compiler's actual Wasm binary under Node's WebAssembly VM, validates emitted modules, executes scalar guest values, checks immutable/mutable declaration rules, tests 100 distinct generated programs, and validates source/compiler failures.

For headless browser smoke (when Chromium is installed): `npm run test:browser`.

## Architecture

- `compiler/atto_compiler.c`: freestanding source parser, restricted type and binding admission, Wasm binary writer.
- `public/atto_compiler.wasm`: shipped compiler Wasm artifact, regenerated by `npm run build:compiler`.
- `src/compiler.js`: shared browser/Node compiler ABI wrapper.
- `src/compiler-worker.js`: disposable compilation worker (3-second deadline).
- `src/runner-worker.js`: disposable untrusted guest worker (3-second deadline, zero imports).
- `src/app.js` + `index.html`: static UI, examples, downloaded Wasm, shareable snippet URLs.

**Important:** Atto canonical compiler repositories `atto-source.rs`, `atto-source.wasm`, `atto-common-source`, and their legacy Oreslang implementations remain the authority for full-language semantics. This bootstrap is not promoted to full AttoLang or compiler parity by its passing demo tests.

## Deployment

Host this directory on any static host, with `.wasm` served as `application/wasm`, strong CSP headers, and no user-controlled backend execution. For a domain like `play.attolang.org`, use a CNAME/host mapping managed by the website owner. The main language website can link directly to the playground. CI checks the compiler regeneration and Node tests; a green run must have nonzero executed job steps.
